# Pixel Sprites Directory

Place your pixel animation sprite sheets here!

## Export Recommendations
- **idle.png**: Horizontal strip of idle frames (e.g. 4 frames of 64x64px = 256x64px total image).
- **speaking.png**: Horizontal strip of speaking frames (e.g. 6 frames of 64x64px = 384x64px total image).

## Drawing Software
- **LibreSprite** (Free/Open Source fork of Aseprite)
- **Pixelorama** (Free/Open Source)
- **Piskel** (Free/Open Source)
